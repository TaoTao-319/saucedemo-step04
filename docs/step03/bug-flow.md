# 缺陷流转记录

## 状态说明

| 状态 | 含义 |
| --- | --- |
| Open | 缺陷已提出，仍待确认、处理或修复 |
| Assigned | 缺陷已分配给具体处理人员 |
| In Progress | 已有人开始处理 |
| Fixed | 开发已完成修复，等待测试验证 |
| Ready for Retest | 已具备复测条件 |
| Closed | 缺陷已验证解决并关闭 |
| Reopened | 复测仍失败，缺陷重新打开 |
