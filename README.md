本次工作的目标是把测试用例、实际结果、缺陷、验收标准、回归记录和 GitHub 项目文件统一为一套可检查的测试资料。

- 统一测试用例总数和测试结果统计；

- 统一缺陷编号、账号、现象、证据和状态；
